# Dos Hermanos Project Skills

These skills govern implementation before application code is generated.

Use only the skills relevant to the task. Do not load every skill by default.

## Routing

- Project scope and technology decisions: `project-foundation/SKILL.md`
- Human-readable implementation style: `coding-readability/SKILL.md`
- Directory and module boundaries: `architecture/SKILL.md`
- Straightforward user flows and interface behavior: `ui-ux/SKILL.md`
- Preventing client-side data exposure: `frontend-security/SKILL.md`
- Firestore authorization rules: `firestore-security/SKILL.md`
- Firestore collections, documents, and query-oriented modeling: `firestore-data-design/SKILL.md`
- Firebase Authentication behavior: `authentication/SKILL.md`
- React + TypeScript + Vite web implementation: `react-web/SKILL.md`
- Expo React Native mobile implementation: `expo-mobile/SKILL.md`
- Efficient reads, bounded growth, and performance: `scalability-performance/SKILL.md`
- Validation, state transitions, and consistency: `validation-data-integrity/SKILL.md`
- Testing and release quality: `testing-quality/SKILL.md`
- Git changes and repository hygiene: `git-workflow/SKILL.md`

## Global precedence

Security and data protection override convenience. Correctness overrides brevity. Simplicity overrides unnecessary abstraction. Project scope overrides speculative features.
